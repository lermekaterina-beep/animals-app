# Приложение «Животные» для iPad

Обучающее приложение для проверки гипотезы: ребёнок ищет домашних животных, а приложение считает время каждого шага, ошибки и оценку сложности.
Формат: альбомная ориентация, iPad (2360 × 1640). Работает в браузере, установка не нужна.

## Как выложить на GitHub и открыть на iPad

1. Зайдите на github.com и создайте репозиторий (кнопка **New**), например `animals-app`, с видимостью **Public**.
2. Нажмите **uploading an existing file** и перетащите в окно **всё содержимое** папки (файлы `index.html`, `style.css`, `app.js`, `icon.png` и папку `assets`). Нажмите **Commit changes**.
   Если папка `assets` не загрузилась целиком, загрузите её вторым заходом, в GitHub можно перетаскивать папки целиком.
3. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку **main** и папку **/ (root)**, нажмите **Save**.
4. Через 1–2 минуты вверху страницы появится ссылка вида `https://ВАШ-ЛОГИН.github.io/animals-app/`.
5. Откройте ссылку в Safari на iPad. Чтобы приложение запускалось на весь экран: **Поделиться → На экран «Домой»**.

## Что где лежит

| Файл | Назначение |
|---|---|
| `index.html` | Страница приложения |
| `style.css` | Стили |
| `app.js` | Вся логика: экраны, таймеры, ошибки, результаты |
| `icon.png` | Иконка для экрана «Домой» |
| `assets/screens/` | Экраны из макета |
| `assets/sprites/` | Вырезанные карточки и анимации (рука, подмигивание) |
| `assets/audio/` | Озвучка |

## Озвучка

Чтобы заменить запись, положите новый mp3 в `assets/audio/` с тем же именем.

| Файл | Где звучит |
|---|---|
| `greeting.mp3` | Первый экран |
| `dir-alphabet.mp3`, `dir-digits.mp3`, `dir-animals.mp3`, `dir-music.mp3`, `dir-drawing.mp3` | Карточки направлений (при клике) |
| `pre-exercise.mp3` | Экран перед упражнением |
| `two-correct.mp3` | После двух верных ответов |
| `error.mp3` | При ошибке (не чаще раза в 4 секунды) |
| `stay.mp3` | Попытка выйти до того, как найдены все четыре животных |
| `rate-exercise.mp3` | Экран оценки |

## Как это работает

- Организатор на экране «Для организатора» вписывает код участника и выбирает упражнение 1–6.
- Ребёнок находит всех четырёх домашних животных, после чего открывается экран оценки.
- Для каждого шага записываются время шага, время от старта и результат (верно, ошибка, повтор). Время отображается по Москве.
- Прервать упражнение можно, удерживая кнопку «Домой» 2 секунды. Прерванное прохождение не сохраняется.
- Раздел «Результаты» показывает таблицу по выбранному прохождению и копирует всё в CSV.

## Важно

- Результаты хранятся **в браузере конкретного устройства**. На другом устройстве они не появятся, поэтому копируйте CSV после каждой сессии.
- Чтобы искать диких животных вместо домашних, в `app.js` найдите `const NEED=1` и замените на `0`.
- Шрифт заголовков загружается из Google Fonts и требует интернета. Остальное работает без сети после первой загрузки.
